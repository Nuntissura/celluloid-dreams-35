# Celluloid Dreams 35 Codex

This file is the stable entry point to the CD35 project authority.

The normative codex is maintained under [`codex/`](./codex/):

- [`codex/authority.md`](./codex/authority.md) — authority, precedence, rule identity, and evidence discipline (`AUTH-*`).
- [`codex/repository-behavior.md`](./codex/repository-behavior.md) — repository structure and change behavior (`REP-*`).
- [`codex/spec-workflow.md`](./codex/spec-workflow.md) — specification creation, revision, promotion, and archival (`WF-*`).
- [`codex/product-build-rules.md`](./codex/product-build-rules.md) — cross-cutting product architecture, standardization, repairability, and component-selection rules (`PBR-*`).

See [`codex/README.md`](./codex/README.md) for the codex index.

The current engineering specification is [`cd35-gov/spec/current/index.md`](./cd35-gov/spec/current/index.md). Archived specification baselines are historical records only.

Rule precedence and exception handling are defined in `AUTH-*`; specification lifecycle is defined in `WF-*`. Normative codex rules use stable IDs so specifications, tests, issues, and design reviews can cite them directly.
