# CD35 Codex

The CD35 codex is the project-wide governance and engineering-rule set.

The root [`codex.md`](../codex.md) is the stable entry point. Normative rules live in the files below.

| Document | Rule prefix | Purpose |
|---|---|---|
| [authority.md](./authority.md) | `AUTH-*` | Authority, precedence, rule identity, evidence discipline |
| [repository-behavior.md](./repository-behavior.md) | `REP-*` | Repository layout and change behavior |
| [spec-workflow.md](./spec-workflow.md) | `WF-*` | Specification creation, revision, promotion, and archival |
| [product-build-rules.md](./product-build-rules.md) | `PBR-*` | Cross-cutting product architecture, modularity, repairability, and part-selection rules |

Rule IDs are designed to be cited from specifications, issues, CAD notes, test plans, and design reviews.
