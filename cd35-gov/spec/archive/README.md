# CD35 Specification Archive

This directory contains immutable snapshots of superseded CD35 specification baselines.

Archive directories use semantic-style version names:

```text
archive/
├── README.md
├── v0.1.0/
├── v0.2.0/
└── ...
```

A baseline is copied here **only when it is being superseded**. Archived files are historical records and must not be edited after creation.

## Archived baselines

- `v0.1.0/` — initial structured concept baseline; superseded by v0.2.0 module-platform architecture.
- `v0.2.0/` — standardized TDM/TSM/FSM/WBM module-platform baseline; superseded by v0.3.0 TRM and thermal-conditioning architecture.

See [`../../../codex/spec-workflow.md`](../../../codex/spec-workflow.md) for the authoritative promotion and archive procedure.
